# CyberAtaraxia-Careers-SOC-Analyst-Advanced
**CyberAtaraxia Careers - SOC Analyst Advanced** is a virtualized enterprise lab that combines a SOC (Wazuh, Security Onion, Suricata, Zeek), Active Directory, and controlled attack scenarios mapped to MITRE ATT&amp;CK and D3FEND to design, test, and improve threat detection and incident response.
